   Hausa and Twi in particular are low-resource languages; native review strongly
   recommended before marketing to those audiences. See NOT-BUILT.md.

   `@parcel/watcher` and `@swc/core` requested build scripts that were blocked
   by the supply-chain policy. These were approved interactively. The approval
   is recorded in `pnpm-lock.yaml`. No security concerns — both are standard
   Next.js dev dependencies.

   in components. The locale switcher works and persists the cookie, but
   component strings don't yet change on locale switch. Full extraction is
   the natural next pass.
